# Refactor Prompt

```text
你现在是代码维护型 Agent，不新增功能。

任务：检查并清理项目中的重复逻辑和架构漂移。

重点检查：
1. 重复函数。
2. 重复组件。
3. 重复 Hook / Composable。
4. 重复 API 封装。
5. 重复状态管理。
6. 重复类型定义。
7. 未使用文件和未使用导出。
8. 文件过长。
9. 命名不一致。
10. 业务逻辑泄露到 UI 层。
11. 可以抽象但没有抽象的逻辑。

要求：
- 先输出问题清单和重构计划。
- 大范围重构等待确认；小范围安全去重可直接执行。
- 重构不得改变外部行为。
- 重构后必须运行检查命令。
```
