# Preflight Prompt

```text
在开始实现前，先做代码盘点。

请搜索项目中是否已有以下内容：

1. 类似组件。
2. 类似 Hook / Composable。
3. 类似 Service / API 封装。
4. 类似 Store / 状态模块。
5. 类似 Utils / Helper。
6. 类似类型定义。
7. 类似样式或设计 token。
8. 类似错误处理、加载状态、空状态。

输出：
- 已找到的可复用文件。
- 不应重复创建的模块。
- 建议修改哪些现有文件。
- 是否真的需要新增文件。
- 是否需要新增依赖。
- 如果用户要求直接实现，盘点后继续执行最小变更。
```
