## 🛠️ Using the governance skill

The software runs as a background service. It connects to your AI coding tools automatically. You do not need to click buttons to make it work. When you ask an AI assistant to write code, this tool watches the request. 

It performs these steps:

1. Search: It checks if the code exists in your project.
2. Architecture Check: It compares new code against your established project layout.
3. Dependency Logic: It verifies that any added libraries are safe and necessary.
4. Verification: It reviews the final code output to ensure it matches your quality standards.

If the tool finds an issue, it sends a notification to your screen. It identifies the problem and suggests a fix. You can ignore the suggestion or click it to apply the change.
