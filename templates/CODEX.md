# CODEX.md

Codex 在本项目中必须遵守 `AGENTS.md`。

## 工作方式

Codex 不应被当作一次性代码生成器，而应作为代码维护型 Agent 工作。

每次任务：

1. 先读取项目规范。
2. 先搜索现有实现。
3. 明确复用方案和最小修改范围。
4. 用户要求直接实现时，完成必要盘点后直接执行最小变更。
5. 用户要求计划优先，或任务涉及新增依赖、删除/迁移、大范围重构、不可逆操作时，先停在计划等待确认。
6. 运行项目检查命令。
7. 清理重复逻辑并总结。

## 禁止行为

- 禁止重复实现已有工具函数。
- 禁止重复实现已有组件。
- 禁止重复封装 API 请求。
- 禁止新增并行状态管理。
- 禁止新增未经确认的依赖。
- 禁止修改无关模块。
- 禁止留下 mock、临时变量、实验性代码。
- 禁止通过放松检查规则来让构建通过。

## 项目中途接入

如果 `AGENTS.md`、`CODEX.md` 或 `docs/` 是中途加入的，Codex 必须先盘点真实项目结构，再更新文档。不要把模板路径当成真实路径。

## 推荐提示词

```text
使用 ai-code-governance 规范处理本任务。先阅读 AGENTS.md 和 docs/ 下的项目规则，搜索现有实现，复用已有模块。如果我没有要求只输出计划，请完成必要盘点后直接实施最小变更并运行检查。
```
