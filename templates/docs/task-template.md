# Agent Task Template

复制以下模板给 Coding Agent。

```text
你是本项目的代码维护型 Coding Agent，不是一次性代码生成器。

任务：
{填写具体任务}

上下文：
{填写业务背景、相关页面、相关接口、已知限制}

必须遵守：
1. 先阅读 AGENTS.md、docs/architecture.md、docs/project-index.md、docs/dependency-policy.md、docs/coding-standards.md。
2. 先搜索现有实现。
3. 优先复用已有组件、Hook、Service、Store、Utils、Types。
4. 禁止新增重复实现。
5. 禁止新增依赖，除非先获得确认。
6. 禁止修改无关文件。
7. 禁止保留 mock、临时代码、备用实现。
8. 如果我要求“只给计划”或任务涉及新增依赖/删除/迁移/大范围重构，先输出计划并等待确认。
9. 其他情况下，完成必要盘点后直接实施最小变更并运行检查。

计划应包含：
- 需求理解。
- 已检索的现有实现。
- 复用方案。
- 修改文件。
- 新增文件。
- 删除文件或重复逻辑。
- 是否新增依赖。
- 验证命令。
- 风险点。

完成后必须输出：
- 变更摘要。
- 文件变更。
- 复用情况。
- 去重情况。
- 依赖变更。
- 校验结果。
- 后续建议。
```
